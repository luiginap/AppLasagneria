COME FARE UN ORDINE
1. Apri l'app → scegli la sede (Notting Hill o Chelsea)
2. Tocca il fornitore che vuoi ordinare
3. Le quantità sono già pre-caricate
4. Se qualcosa avanza → premi ➖ per ridurre
5. Se serve di più → premi ➕
6. Per escludere un articolo → spegni il toggle
7. Tocca 📋 COPIA
8. Vai su WhatsApp → apri la chat del fornitore → tieni premuto nel campo testo → Incolla → Invia

📦 AGGIUNGI PRODOTTI EXTRA
Tocca la barra arancione "Aggiungi se serve" → attiva quello che ti serve → finisce nel messaggio automaticamente

🔄 RESET
Se vuoi tornare ai valori standard → tocca Reset

⚠️ IMPORTANTE
Non contare lo stock — le quantità sono già calibrate sui consumi reali. Cambia solo se quella settimana è diversa (evento, chiusura ecc.)

Se qualcosa finisce sempre prima o avanza sempre → scrivi a Luigi 👍
